# Internacionalizace (CS)

🇨🇿 Česky · [🇬🇧 English](i18n.en.md)

## Principy

- Dva jazyky: `cs` (výchozí, v kořeni) a `en` (pod `/en`). Seznam je v `src/i18n/config.ts`.
- **Přeložené URL.** Jazykově nezávislé ID nástroje (`TOOL_IDS`: `timer`, `meditation`, `passwords`, `invoice`)
  se v `TOOL_SLUGS` mapuje na slug pro každý jazyk, např. `meditation` → `/meditace` (cs), `/en/meditation` (en).
  Odkazy vždy skládej přes `toolPath(locale, id)` / `homePath(locale)` / `pagePath(locale, id?)`, nikdy ručně.
- **Bez i18n knihovny a bez proxy.** Každý jazyk má vlastní route group s vlastním root layoutem (tedy vlastním
  `<html lang>`): `src/app/(cs)/…` a `src/app/(en)/en/…`. Všechny stránky se prerenderují staticky. Automatické
  přesměrování podle `Accept-Language` není, jazyk přepíná uživatel v hlavičce.
- Obě sady URL jsou plnohodnotné indexovatelné stránky: každá nastavuje `canonical` a `hreflang`
  (`toolMetadata()` / `homeMetadata()`), `metadataBase` se bere z `NEXT_PUBLIC_SITE_URL`.

## Struktura

```
src/i18n/
  config.ts        jazyky, ID nástrojů, slugy, pomocníci pro cesty
  dictionaries.ts  skládá slovníky; typ určuje čeština
  format.ts        fmt("{n} kol", { n }) a plural(locale, forms, n)
  provider.tsx     I18nProvider + hooky useLocale / useCommon / useToolMessages
  messages/
    common.{cs,en}.ts    hlavička, přepínač motivu, patička
    catalog.{cs,en}.ts   karta na rozcestníku + úvod stránky každého nástroje
    <tool>.{cs,en}.ts    UI texty nástroje
src/tools/<id>/    klientské komponenty nástrojů (společné pro oba jazyky)
src/app/(cs)/…     české routy (tenké page.tsx)
src/app/(en)/en/…  anglické routy (tenké page.tsx)
```

- **Zdrojem pravdy je čeština.** `xxx.cs.ts` je obyčejný objekt, `xxx.en.ts` je typovaný `typeof xxxCs`, takže
  chybějící nebo přebývající klíč v angličtině shodí `pnpm typecheck`.
- Slovníky musí zůstat **serializovatelné** (řetězce, pole, objekty — žádné funkce), protože je server předává
  klientským komponentám. Použij zástupce `{name}` s `fmt()` a `plural()` pro množná čísla (čeština má
  `one`/`few`/`other`, angličtina `one`/`other`).
- Klientské komponenty čtou texty přes `useToolMessages("<id>")`; obal `<ToolPage>` posílá do klienta jen texty
  daného nástroje (+ `common`).
- Čistá logika v `src/lib/` neobsahuje uživatelské řetězce — vrací klíče/úrovně a text vybírá UI.
- Klíče `localStorage` jsou jazykově nezávislé (`tools.<slug>.…` s původním českým slugem), takže se nastavení
  sdílí mezi jazyky.

## Přidání nástroje

1. Kód do `src/tools/<id>/`, logika do `src/lib/`.
2. `src/i18n/config.ts`: přidej ID do `TOOL_IDS` a slug pro každý jazyk do `TOOL_SLUGS`.
3. `src/i18n/messages/`: kartu a úvod přidej do `catalog.cs.ts` / `catalog.en.ts`, vytvoř `<id>.cs.ts` a
   `<id>.en.ts` a zapoj je v `dictionaries.ts` (objekty `cs` a `en`).
4. Ikonu přidej do `TOOL_ICONS` v `src/components/home-page.tsx`.
5. Vytvoř `src/app/(cs)/<slug>/page.tsx` a `src/app/(en)/en/<slug>/page.tsx`:

   ```tsx
   import { ToolPage, toolMetadata } from "@/components/tool-page";
   import { MyTool } from "@/tools/<id>/my-tool";

   export const metadata = toolMetadata("cs", "<id>");

   export default function Page() {
     return (
       <ToolPage locale="cs" tool="<id>">
         <MyTool />
       </ToolPage>
     );
   }
   ```
6. Doplň tabulky v README (oba jazyky), spusť `pnpm typecheck` a `pnpm build`.

## Přidání jazyka

1. Přidej kód do `LOCALES` v `src/i18n/config.ts` a slug do každého záznamu `TOOL_SLUGS`.
2. Vytvoř `*.<lang>.ts` pro každý modul textů (typovaný podle češtiny) a zaregistruj ho v `dictionaries.ts`.
3. Přidej `src/app/(<lang>)/layout.tsx` (zkopíruj `(en)`), stránky `src/app/(<lang>)/<lang>/…` a
   `public/manifest.<lang>.json`.
4. Doplň název jazyka do `common.languageNames` ve všech slovnících.
